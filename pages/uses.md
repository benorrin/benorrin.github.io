This is my [/uses page](https://uses.tech/): a list of the tools I use, kept partly for curious visitors and partly so I remember what I've set up. Free and open-source software, and keeping my data private, matter to me, so FOSS wins wherever there's a good option.

## Desk

| **Computer** | A custom-built desktop PC |
| **OS** | [openSUSE Tumbleweed](https://get.opensuse.org/tumbleweed/) |
| **Desktop** | [KDE Plasma](https://kde.org/plasma-desktop/) |
| **Phone** | iPhone 16 Pro Max |

## Software

| **Editor (home)** | [Kate](https://kate-editor.org/), KDE's own text editor |
| **Editor (work)** | [VS Code](https://code.visualstudio.com/) |
| **Editor (heart)** | [GNU Emacs](https://www.gnu.org/software/emacs/). I'm still fond of it, but it can be hard work next to modern editors |
| **Browser** | [LibreWolf](https://librewolf.net/), a privacy-focused Firefox fork |
| **Email** | [Thunderbird](https://www.thunderbird.net/) |
| **Keep-awake** | [Geekoffee](/projects/geekoffee.html), a tray app I wrote because I kept needing one |

## Homelab

A Raspberry Pi running [Debian](https://www.debian.org/), with everything in Docker containers managed by Docker Compose. It's small, quiet and cheap to run, and it's where most of my [side projects](/projects/) start.

| Service | What it's for |
|---|---|
| [Jellyfin](https://jellyfin.org/) | Films and TV, streamed around the house |
| [Audiobookshelf](https://www.audiobookshelf.org/) | Audiobooks and podcasts, with progress synced across devices |
| [Immich](https://immich.app/) | Photo and video backup, instead of a big-tech cloud |
| [Paperless](https://docs.paperless-ngx.com/) | Scanned letters and documents, OCR'd and searchable |
| [Uptime Kuma](https://github.com/louislam/uptime-kuma) | Keeps an eye on everything else and tells me when it falls over |
| [Speedtest Tracker](https://github.com/alexjustesen/speedtest-tracker) | Logs my broadband speed over time |
