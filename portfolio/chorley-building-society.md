## The brief

[Chorley Building Society](https://www.chorleybs.co.uk/) wanted a modern website. That meant a full redesign, a move to the Umbraco CMS, and hosting that could handle more traffic reliably. Off-the-shelf Umbraco didn't cover everything they needed, so the CMS also had to be extended with custom code.

![The new Chorley Building Society website](/assets/img/chorley-building-society.jpg)

## What I did

* **Led the AWS infrastructure.** I designed, configured and managed the hosting so the new site could scale with traffic and stay reliable.
* **Extended Umbraco.** I helped configure the CMS and wrote custom C# to add the features the society needed.
* **Backend development.** I built C# backend code to support the site's new features and integrations.

## The result

* **A redesigned, modern website** running on Umbraco CMS
* **Scalable, reliable AWS hosting** built for higher traffic
* **Custom CMS features** that met the client's specific requirements
